# Baseline Report - 2026-11-02

## D1: Install fails

Command: `pip install -e .`

Result: FAILED - `pyproject.toml` has Poetry-style `authors = ["..."]` but PEP 621 needs object format. Exit code: 1

## D2: All runtime deps unused

Listed 10 dependencies in pyproject.toml. Code imports only stdlib (sqlite3, hashlib). All 10 deps unused.

## D3: _uid() collisions

Test: 2000 IDs -> only 53 unique (97.4% collision rate). Collision-prone ID generator.

## D4: As-of reconstruction broken

materialize_world_state_at returns 0 claims/observations/relationships. Entities ignore time, claims from current projection, relationships use >=.

## D5: Original content not preserved

documents has no content column (only SHA-256). canonical_url hardcoded to example.com/doc. extract_source_span accepts any text.

## D6: Engine ignores validator

Demo's RevisionEngine writes CONTESTED regardless of validation result. validate_proposal raises IndexError on empty entity.

## D7: Audit chain not chained

previous_hash always NULL, event_hash does not include prior hash. Tampering undetectable.

## D8: from reality_engine import * raises

__all__ lists 'Database' but it is never imported as a module-level name.

## D9: Valid time conflated with transaction time

submit_claim sets valid_from = recorded_at. v1 claim_versions row has valid_to = recorded_at (zero-length interval). Version id equals claim id.

## D10: Entity resolution silently wrong

resolve_entity uses LIMIT 1. Two entities aliased 'georgia' resolve to one arbitrary ID. resolve('inflation') returns None (un-normalized compare).

## D11: Transactions and WAL claimed, not real

Every method commits individually. journal_mode returns 'delete' not 'wal'. delete_entity fails FK and violates P4 (never erase history).

## D12: Demo lies

Prints 'All steps executed successfully' unconditionally. Steps numbered [1]...[11] not [0]...[7]. Hard-coded /Users/... paths.

## Summary

All 12 defects (D1-D12) reproduced and documented. Phase 1: Fix install, CI, dependencies.
