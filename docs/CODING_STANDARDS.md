# Coding Standards

**Reality Engine — Coding Standards Document**
**Version:** 0.1.0
**Date:** November 1, 2026

This document defines the coding standards of Reality Engine. It covers formatting, linting, typing, testing, and documentation.

---

## 1. Coding Standards Overview

- **Formatting:** Use the project's formatter.
- **Linting:** Use the project's linter.
- **Typing:** Use type annotations.
- **Tests:** All code must be covered by tests.
- **Documentation:** All public APIs must be documented.

---

## 2. Constraints

1. **The system must be developed locally-first.**
2. **The system must be developed as a modular monolith.**
