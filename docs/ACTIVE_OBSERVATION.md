# Active Observation

**Reality Engine — Active Observation Document**
**Version:** 0.1.0
**Date:** November 1, 2026

This document defines the Active Observation of Reality Engine. It covers the knowledge gaps and the observation priority.

---

## 1. Active Observation Overview

Active observation is the process by which the system identifies gaps in its understanding and determines which additional observations would most improve its understanding.

---

## 2. Knowledge Gaps

Examples:

- A major economic indicator has not been updated.
- Two official datasets disagree.
- A reported event lacks independent confirmation.
- A critical entity has incomplete historical records.
- A hypothesis depends on an outdated measurement.
- A source has stopped publishing.

---

## 3. Observation Priority

The observation priority is an initial heuristic, not a statistically validated formula:

```text
Observation Priority =
    Potential Information Value
  × Uncertainty Reduction
  × Domain Relevance
  × Time Sensitivity
  / Collection Cost
```

**Constraint:** This is an initial heuristic, not a statistically validated formula. The system should eventually measure whether acquiring the suggested information actually improves its world model.

---

## 4. Constraints

1. **The observation engine may autonomously collect from approved public sources within defined limits.**
2. **The observation engine must not bypass access controls.**
3. **The observation engine must not circumvent paywalls.**
4. **The observation engine must not violate source terms.**
