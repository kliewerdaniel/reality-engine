# Collection Scheduler

**Reality Engine — Collection Scheduler Document**
**Version:** 0.1.0
**Date:** November 1, 2026

This document defines the collection scheduler of Reality Engine. It covers collection priority and the budget allocation.

---

## 1. Collection Scheduler Overview

The collection scheduler coordinates the collection of documents from sources.

---

## 2. Scheduling Factors

Collection priority should be configurable. Potential factors:

- Source update frequency
- Domain importance
- Historical reliability
- Information freshness
- Resource cost
- Unresolved knowledge gaps

---

## 3. Budget Allocation

The scheduler must not allow one high-volume source to consume the entire processing budget.

---

## 4. Constraints

1. **The scheduler must not allow one high-volume source to consume the entire processing budget.**
