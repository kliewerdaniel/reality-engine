# Data Privacy

**Reality Engine — Data Privacy Document**
**Version:** 0.1.0
**Date:** November 1, 2026

This document defines the data privacy of Reality Engine. It covers the privacy of public and private information.

---

## 1. Data Privacy Overview

The initial application should prioritize public information. Private data integrations must require explicit authorization and appropriate access controls. Public and private information must have separate access boundaries.

---

## 2. Constraints

1. **The initial application should prioritize public information.**
2. **Private data integrations must require explicit authorization and appropriate access controls.**
3. **Public and private information must have separate access boundaries.**
