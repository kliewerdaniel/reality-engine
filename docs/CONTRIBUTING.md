# Contributing

**Reality Engine — Contributing Document**
**Version:** 0.1.0
**Date:** November 1, 2026

This document defines the contributing guidelines for Reality Engine. It covers the contribution process, the contribution requirements, and the contribution review.

---

## 1. Contributing Overview

Contributions to Reality Engine are welcome.

---

## 2. Contribution Process

1. **Fork the repository.**
2. **Create a branch.**
3. **Make changes.**
4. **Run the tests.**
5. **Commit changes.**
6. **Open a pull request.**

---

## 3. Contribution Requirements

- **All code must be covered by tests.**
- **All public APIs must be documented.**
- **All documentation must be up to date.**

---

## 4. Contribution Review

Contributions will be reviewed for:

- **Correctness.**
- **Test coverage.**
- **Documentation.**
- **Consistency with the architecture.**

---

## 5. Constraints

1. **Contributions are welcome.**
2. **All code must be covered by tests.**
3. **All public APIs must be documented.**
