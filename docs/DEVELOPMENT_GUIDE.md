# Development Guide

**Reality Engine — Development Guide Document**
**Version:** 0.1.0
**Date:** November 1, 2026

This document defines the development guide of Reality Engine. It covers the development environment, the development workflow, and the coding standards.

---

## 1. Development Environment

**Prerequisites:**

- Python 3.11+
- SQLite 3
- Node.js 18+
- Git

---

## 2. Development Workflow

1. **Clone the repository.**
2. **Create a virtual environment.**
3. **Install dependencies.**
4. **Run the tests.**
5. **Make changes.**
6. **Run the tests.**
7. **Commit changes.**
8. **Open a pull request.**

---

## 3. Coding Standards

- **Formatting:** Use the project's formatter.
- **Linting:** Use the project's linter.
- **Typing:** Use type annotations.
- **Tests:** All code must be covered by tests.
- **Documentation:** All public APIs must be documented.

---

## 4. Constraints

1. **The system must be developed locally-first.**
2. **The system must be developed as a modular monolith.**
3. **The system must be developed using an event-driven, event-sourced architecture.**
