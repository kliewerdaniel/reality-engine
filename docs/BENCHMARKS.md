# Benchmarks

**Reality Engine — Benchmarks Document**
**Version:** 0.1.0
**Date:** November 1, 2026

This document defines the benchmarks of Reality Engine. It covers the benchmark categories and the benchmarks.

---

## 1. Benchmark Categories

| Benchmark | Measurement |
|---|---|
| Extraction | Claim extraction precision, recall, entity extraction accuracy, event extraction accuracy, temporal extraction accuracy |
| Provenance | Percentage of claims traceable to correct original source passages |
| Temporal | Delayed reporting, corrected publication dates, retroactive policy changes |
| Revision | Correctly affected claims, incorrectly affected claims, missed dependencies, invalid revision acceptance, unnecessary revision frequency |
| Contradiction | Genuine contradictions, apparent contradictions, delayed reporting, corrected publications, retracted publications |
| Forecast Calibration | Accuracy against proper scoring rules and baseline models |

---

## 2. Constraints

1. **Reality Engine must be evaluated on the correctness of its knowledge operations, not the fluency of its generated explanations.**
2. **A convincing answer is not necessarily a correct answer.**
